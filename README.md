# tinto.

**Café oscuro, trabajo claro**

Sitio web oficial de **tinto.**, marca colombiana de café de especialidad que combina tostión, cafetería de grano entero, café para llevar y espacio de coworking.

## Sobre el proyecto

Este repositorio contiene el frontend del sitio de tinto., desarrollado con Bootstrap, incluyendo:

- Sección de ubicaciones (Tinto Café Centro y Tinto Café Norte)
- Componentes personalizados (navbar flotante, input de newsletter, etc.)
- Sistema visual de marca: paleta Grafito, Blanco hueso, Concreto y Vinotinto, con tipografía Playfair Display + Manrope + Space Mono

## Tecnologías

- HTML5 semántico (BEM)
- Bootstrap
- CSS / JS

## Cómo correr el proyecto localmente

```bash
git clone https://github.com/ozmarrugo-dev/tinto-proyecto-final.git
cd tinto-proyecto-final
npm install
```
